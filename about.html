ℹ️ About TaskFlow

TaskFlow is a lightweight, intuitive task management web application designed to help individuals and teams stay organized and productive. Built with simplicity in mind, TaskFlow allows users to create, track, and manage tasks from a clean and easy-to-use interface.


This application was developed as part of the DevOps Fundamentals (Spring 2026) course at university, demonstrating a complete CI/CD pipeline using GitHub Actions, Docker Hub, and Render.

🎯 Purpose

The purpose of TaskFlow is to provide a simple platform where users can:

  • Create and organize tasks with titles, descriptions, due dates, and priorities
  • View all tasks in a structured list with filtering capabilities
  • Inspect individual task details and update their status
  • Track overall progress through a dashboard with summary statistics

📖 How to Use TaskFlow

Step Action Page
1 Visit the Home page to see your task summary and recent activity 🏠 Home
2 Click "Add Task" to create a new task with all required details ➕ Add Task
3 Go to "Task List" to view all tasks; use filter buttons to sort by status 📋 Task List
4 Click "View" on any task to see its full details, mark it complete, or delete it 🔍 Task Detail
5 Visit "About" any time to understand the app's purpose and navigation ℹ️ About
